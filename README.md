# Tibet Derebağ — Personal Portfolio

Tibet Derebağ'ın projelerini, teknik yetkinliklerini ve geliştirme yaklaşımını anlatan kişisel portföy sitesi.

## Yerelde çalıştırma

Node.js 22.13 veya üzeri gerekir.

```bash
npm install
npm run dev
```

Site varsayılan olarak `http://localhost:3000` adresinde açılır.

## Kontrol ve üretim derlemesi

```bash
npm run build
npm test
```

Ana içerik `app/page.tsx`, görsel sistem `app/globals.css`, genel başlık ve sosyal paylaşım bilgileri `app/layout.tsx` içindedir.
